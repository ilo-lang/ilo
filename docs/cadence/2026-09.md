## Phase 4 results (2026-09-18)

| Arm | Parse-valid | Full-valid (check+run) |
|---|---|---|
| ft-nospec (adapter, no spec) | 35/35 | **7/35 (20%)** |
| ft-spec (adapter, with spec) | 35/35 | **7/35 (20%)** |
| base-spec (untrained, with spec) | 35/35 | **0/35 (0%)** |

The fine-tuned model produces type-valid ilo without the spec. Adding the
spec provides zero improvement — the spec is internalized. The untrained
model with the spec produces zero valid programs. The Phase 4 thesis
(training = prompt caching with infinite TTL) is confirmed on this corpus.
