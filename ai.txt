INTRO: ilo is a token-optimised, prefix-notation language for AI agents. Every token is counted: generation + retries + context loading.

QUICK START: Function: `f x:n>n;+x 1`. Entry point: `main>_;prnt "hello"`. Types: n=number t=text b=bool _=any L n=list R n t=result. Prefix ops: `+a b` `*a b` `-a b` `/a b` `>a b` `=a b` `!b`. No infix needed. Semicolons separate statements. Last expression returns. Comments: `--`.

SPACING: Every token needs whitespace. `90"A"` fails — write `90 "A"`. `func(x)2` fails — write `func (x) 2` or `func x 2`.

MODULES: Load only what the task needs. Each module is 1-4K tokens.
  ilo skill get ilo-language      syntax, types, operators, guards, match, ternary, pipes, records
  ilo skill get ilo-builtins-core list, map, HOFs (map/flt/fld), result unwrap, type coercions
  ilo skill get ilo-builtins-math arithmetic, stats, rounding (rou x digits), trig
  ilo skill get ilo-builtins-text strings, regex, fmt, fmt2, CSV/TSV, dates
  ilo skill get ilo-builtins-io   files, HTTP, JSON, env, env-or, time, process, zgunzip
  ilo skill get ilo-errors        diagnostic codes, fix plans, repair loop contract
  ilo skill get ilo-edit-loop     how to read ILO-XXXX errors and iterate
  ilo skill get ilo-tools         MCP server, external tool calls
  ilo skill get ilo-agent         agent patterns: tool use, data pipelines, servers

RESERVED NAMES: All 1-3 char lowercase identifiers are likely builtins. Use 4+ chars for locals. Common traps: tl len sum map cat str avg fmt fld flt srt at hd pi rd wr num ord rev run sin mod now env. Full list: `ilo skill get ilo-language`.

ENGINE: Tree-walking interpreter (default). Register VM + Cranelift JIT for hot paths. `ilo build` produces native AOT binary. Cross-engine: all tests run on all backends.

EXAMPLES:
  Triangular: main>n;s=*n +n 1;/s 2;s
  Pipeline: main>n;xs=range 1 6;fld {a x>+a x} flt {x> >x 10} map {x>*x x} xs 0
  Safe divide: div a:n b:n>n;=b 0 0;/a b
  Read env: main>t;prnt env-or "HOME" "/tmp"
