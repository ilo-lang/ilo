ilo/closed-loop benchmark

8 runs · newest 2026-09-18 20:32:03
A model writes each task in each language, the program is run, and its error is fed back until it works — that repair loop is the “closed loop”. Measured per attempt-set, retries and repairs included: tokens, emitted characters, dollars and seconds. Program runtime is a different bench (bench/run.sh).
What the run names mean
warm cache
The provider's prefix cache is reused between repair turns, so repeated prompt prefixes bill at the cache rate. cold busts the cache on every attempt — an upper bound on input cost.
aligned
The spec sits in the system message and repairs append turns, so the cached prefix survives the retry. rewritten prompt is the older shape: each repair rewrites the prompt, which breaks the prefix on purpose.
curated / core / full spec
How much of ilo's own skill documentation the model was given in context. Comparators get their language's native agent-facing docs bundled instead.
What the numbers mean
generation tokens
Everything the model emitted, reasoning included — across every attempt of the row, so retries, repairs and discarded drafts are in the count. Total sums every task-row; gen/row divides by task-rows.
code characters
Characters of the emitted program only — reasoning excluded — summed over every attempt, superseded drafts included. It cannot be divided by gen tokens to get a density: those tokens are mostly reasoning, so the ratio measures thinking, not code.
chars/att
Emitted-code characters per attempt: how much program one try writes. Reasoning-free on both sides, so unlike a chars÷tokens ratio it is comparable across legs and models.
tok/char
Generation tokens (reasoning included) per character of emitted code — a price, not a density. Lower is cheaper per character produced.
expects
The exact stdout a row must print to count as working. ↵ marks a line break; a row that runs but prints anything else is partial.
closed loop
The program is written, run, and its error fed back to the model, which rewrites it — repeated until it prints expects or the retry cap is reached. That feedback edge is the loop; an open-loop measure would count tokens to produce code it never ran.
execution time
Wall time of the whole attempt-set — every generation call plus every run of the program. It is not the program's own runtime (that is the wall-clock microbench in bench/run.sh).
input tokens
Prompt tokens sent to the provider across every attempt of the row (spec + task + repairs), before cache discounts.
total tokens
Generation plus input, summed over every attempt: the whole provider-side volume a leg moved in this tab. It is a size, not a price — cache hits bill cheaper but count the same, so spend is the cost figure. Per row divides by task-rows, which makes it comparable across tabs with different task counts.
reps
Measurements averaged into a task-row. The comparator matrix measures the ilo arm once per comparator leg, so ilo rows show ×N.
working
Measurements (reps, not task-rows) whose program ran and printed the expected output within the retry cap. Cells read passed/taken — 6/8 — and the denominator is reps, because the comparator matrix measures the ilo arm once per comparator leg.
best
In a per-task table, the fewest generation tokens among the languages that solved that task. It says who got there with the least emitted text, not who is fastest overall.
outcomes
Roll-up chips in the language table counting task-rows by outcome — one per row of the per-task tables. A row stands for all of its reps, so this is coarser than the rep-based working cell beside it: a row of 6 measurements that passed 5 reads as partial, one chip.
not measured
This language has no row on this task in this tab — the sweep has not run it yet, or it is absent from this run's legs. It is a gap in coverage, never a result.
trunc
Attempts that stopped at the model's output-token cap (finish_reason=length) and emitted no code at all. A truncated attempt is billed like any other and reads as an ordinary failure, so a non-zero count here means the row is measuring the cap, not the language. A dash means the run predates this field.
